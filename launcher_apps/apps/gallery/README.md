# App de Galeria / Imagens - TeamOS 3.0

App nativo de visualização de imagens do sistema.

## Funções planejadas

- Visualizar fotos e imagens
- Grade de miniaturas (estilo One UI / Android)
- Zoom e visualização em tela cheia
- Compartilhar / excluir / editar básico
- Integração com a loja de papéis de parede

## Estilo

Seguindo Material 3 Expressive + One UI (bordas arredondadas, animações suaves, cards).
