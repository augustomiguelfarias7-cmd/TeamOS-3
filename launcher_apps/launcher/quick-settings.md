# Quick Settings / Painel de Notificações - TeamOS 3.0

Inspirado no Android 16 (Material 3 Expressive) + One UI.

## Tiles / Controles planejados

- Wi-Fi (conectar em roteador)
- Dados móveis
- Bluetooth
- Modo Avião
- Lanterna
- Não perturbar
- Localização
- Brilho da tela (slider)
- Rotação automática da tela
- Chamadas / Mensagens (atalhos)
- Bloquear / Desbloquear tela

## Estilo visual

- Fundo com blur (frosted glass)
- Tiles arredondados (estilo One UI + Android 16)
- Tiles redimensionáveis (1x1 e 2x1)
- Cores dinâmicas baseadas no wallpaper
- Animações springy
